# Крипто-сигналы в Telegram

Бот каждые 15 минут смотрит топ-10 монет на Binance и, если сходятся условия стратегии, присылает в Telegram сигнал на покупку или продажу со стопом и тейком. Раз в неделю (и по кнопке) прогоняет стратегию на истории за год и присылает отчёт.

Работает бесплатно на GitHub Actions. Свой сервер не нужен, компьютер можно выключать.

> Это не финансовая рекомендация. Бот не знает будущего, он проверяет правила. Сначала смотри бэктест, потом долго наблюдай сигналы без денег.

## Как устроен сигнал

1. **Тренд 4h** (обязательно). Покупка только если цена выше EMA200 и EMA50 выше EMA200. Продажа наоборот.
2. **Триггер 15m** (обязательно). Гистограмма MACD пересекла ноль в сторону тренда, цена по ту же сторону от EMA55.
3. **Подтверждения**, нужно минимум 3 из 4: ADX ≥ 20, RSI в зоне 50–70 (для продажи 30–50), объём выше среднего в 1.2 раза, тренд 1h в ту же сторону.
4. **Стоп** 1.5 ATR, **тейк** 3 ATR. После сигнала по монете пауза 2 часа.

Все числа в `config.py`, их можно менять.

## Запуск, шаг за шагом

### 1. Создай бота
В Telegram найди **@BotFather**, отправь `/newbot`, придумай имя. Он пришлёт токен вида `123456:ABC-...`. Никому его не показывай.

Напиши своему новому боту любое сообщение, например `/start`.

### 2. Узнай свой chat_id
На компьютере с Python:
```
pip install requests
python get_chat_id.py ТВОЙ_ТОКЕН
```
Он напечатает число, это и есть `chat_id`.

### 3. Залей код на GitHub
1. Зарегистрируйся на github.com.
2. **New repository**, имя любое, тип **Public** (почему публичный, ниже).
3. **Add file → Upload files**, перетащи все файлы из этой папки. Папку `.github` тоже: она скрытая, в Windows включи показ скрытых файлов.

### 4. Спрячь токен в секреты
В репозитории: **Settings → Secrets and variables → Actions → New repository secret**. Создай два:
- `TELEGRAM_TOKEN` с токеном бота;
- `TELEGRAM_CHAT_ID` с числом из шага 2.

В публичном репозитории секреты не видны никому, в коде их нет.

### 5. Запусти
Вкладка **Actions**. Если просит, нажми зелёную кнопку включения.
1. Слева **«Бэктест за год»** → **Run workflow**. Через 5–15 минут в Telegram придёт отчёт и график.
2. Слева **«Сигналы каждые 15 минут»** → **Run workflow** для проверки. Дальше он запускается сам.

## Важные ограничения

- **Почему Public.** Для публичных репозиториев GitHub Actions бесплатен без лимита. В приватном на бесплатном аккаунте 2000 минут в месяц, а запуск каждые 15 минут это около 2900 запусков в месяц, не влезет. Если нужен приватный, поменяй в `signals.yml` расписание на `*/30 * * * *`.
- **Опоздания.** GitHub запускает по расписанию «примерно», бывает задержка 5–20 минут, иногда запуск пропускается. Бот смотрит 3 последние свечи, так что сигнал обычно не теряется, но может прийти позже.
- **Блокировка Binance в США.** Серверы GitHub стоят в США, а Binance блокирует американские IP (ошибка 451). Бот сначала идёт через зеркало `data-api.binance.vision`. Работает ли оно с серверов GitHub, заранее проверить не удалось. Если не работает, бот пришлёт в Telegram сообщение «не может получить данные Binance», и тогда проще запускать его на своём компьютере (ниже).
- **60 дней тишины.** Насколько я знаю, GitHub отключает расписание в публичном репозитории, если в нём 60 дней не было коммитов. Раз в месяц-два поменяй что-нибудь в README.

## Запуск на своём компьютере (запасной вариант)

```
pip install -r requirements.txt
set TELEGRAM_TOKEN=твой_токен          (Windows CMD; в PowerShell: $env:TELEGRAM_TOKEN="...")
set TELEGRAM_CHAT_ID=твой_chat_id
python backtest.py --telegram          бэктест за год
python live.py                         одна проверка сигналов
python live.py --dry                   проверка без отправки в Telegram
```
Чтобы `live.py` запускался каждые 15 минут, добавь его в Планировщик заданий Windows.

## Файлы

| Файл | Что делает |
|---|---|
| `config.py` | все настройки |
| `strategy.py` | правила сигнала (одинаковые для бэктеста и живого режима) |
| `indicators.py` | EMA, RSI, MACD, ATR, ADX |
| `binance_data.py` | загрузка свечей и топ-10 монет |
| `backtest.py` | проверка на истории, отчёт `reports/report.md`, `trades.csv`, `equity.png` |
| `live.py` | одна проверка рынка и отправка сигналов |
| `telegram_api.py` | отправка в Telegram |
| `get_chat_id.py` | узнать chat_id |
