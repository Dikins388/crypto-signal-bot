# Крипто-помощник трейдера в Telegram

Бот следит за рынком Binance вместо тебя и пишет в Telegram, когда происходит что-то важное. Работает бесплатно на GitHub Actions, просыпается каждые 15 минут. Компьютер можно выключать.

> Не финансовая рекомендация. Бот сообщает факты о рынке и проверяет правила, будущего он не знает.

## Что бот присылает сам

| | Событие | Когда |
|---|---|---|
| ⚡ | Резкое движение | цена за час прошла минимум 2% и в 3 раза больше обычного для этой монеты |
| 📊 | Всплеск объёма | за 15 минут проторговали в 4+ раза больше обычного, цена сдвинулась |
| 🚀🔻 | Пробой уровня | закрытие выше вчерашнего/недельного максимума или ниже минимума |
| 🔔 | Твой алерт | цена дошла до уровня, который ты задал командой |
| ☀️ | Утренняя сводка | в 9:00 по Киеву: тренд BTC, индекс страха и жадности, топ-10, лидеры роста и падения |
| 🧪 | Сигнал (эксперимент, сейчас выключен) | стратегия на 4h; каждая сделка пишется в дневник, бот сообщает её итог |

Сканер следит за 20 самыми торгуемыми монетами, сигналы и сводка по топ-10.

## Команды

| Команда | Что делает |
|---|---|
| `/price btc eth` | цены, изменение за 24ч, диапазон, объём |
| `/alert btc 65000` | сообщить, когда цена дойдёт до уровня |
| `/alerts` | список алертов |
| `/del 3` | удалить алерт №3 |
| `/top` | лидеры роста и падения за 24ч |
| `/digest` | сводка рынка прямо сейчас |
| `/stats` | статистика дневника сигналов |
| `/mute`, `/unmute` | выключить/включить сканер (алерты и сводка остаются) |
| `/help` | помощь |

⏱ Бот не висит онлайн, а просыпается раз в 15 минут. Поэтому на команды он отвечает с задержкой до 15 минут. Слушается только владельца (TELEGRAM_CHAT_ID), чужим не отвечает.

## Про экспериментальные сигналы

Стратегия: тренд на дневке (EMA50/EMA200), вход на 4h по MACD, подтверждения ADX, RSI, объёмом. Стоп 1.5 ATR, тейк 3 ATR.

**Сейчас выключены** (`SIGNALS_ENABLED = False`). На 15-минутках стратегия за год была сильно убыточной (Profit factor 0.67), на 4h лучше, но тоже в минусе (Profit factor 0.86, 184 сделки). Если всё же включить, каждый сигнал бот записывает как виртуальную сделку и сам сообщает, чем она закончилась. `/stats` показывает честную статистику на живом рынке. Пока там меньше 30 сделок, выводы делать рано.

## Настройка

Всё в `config.py`: пороги сканера, количество монет, час сводки, параметры стратегии.

## Установка с нуля

1. В Telegram у **@BotFather** создать бота (`/newbot`), получить токен, написать боту `/start`.
2. Узнать chat_id: открыть в браузере `https://api.telegram.org/botТОКЕН/getUpdates` и найти `"chat":{"id":`.
3. Залить файлы в **публичный** репозиторий GitHub (вместе с папкой `.github`).
4. **Settings → Secrets and variables → Actions**: секреты `TELEGRAM_TOKEN` и `TELEGRAM_CHAT_ID`.
5. **Actions** → «Бот каждые 15 минут» → Run workflow.

## Ограничения

- Публичный репозиторий нужен потому, что для него GitHub Actions бесплатен без лимита. В приватном 2000 минут в месяц, этого не хватит на запуск каждые 15 минут.
- GitHub запускает по расписанию с опозданием до 5–20 минут, иногда пропускает запуск.
- Насколько я знаю, GitHub отключает расписание в публичном репозитории после 60 дней без коммитов.
- Память бота (алерты, дневник) хранится в кэше GitHub Actions. Если кэш пропадёт, алерты придётся создать заново.

## Запуск на своём компьютере

```
pip install -r requirements.txt
python run.py --dry          проверка без Telegram
python backtest.py           бэктест за год (нужны TELEGRAM_* только с --telegram)
```
